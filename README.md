# Flor-e-Gr-o
A Flor &amp; Grão tem como missão promover saúde e bem-estar por meio de produtos naturais de qualidade. Sua visão é tornar-se referência no mercado de produtos naturais e comércio digital.  Seus valores são baseados em sustentabilidade, qualidade, transparência, respeito ao cliente e incentivo a hábitos de vida saudáveis.
